A make.fun entry for [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc): one single line that makes office life funny.

## The line

> Our 9 am stand-up runs so long the coffee machine files a harassment claim for being stared at all morning.

The stand-up that never ends, told from the coffee machine's point of view — a real office detail (the 9 am stand-up, the coffee machine) with the laugh landing in the last few words.

## How it works

`main.ts` (Node 22, stdlib only, no network, no external files) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). A gate guard throws unless the line is 1–199 characters, not only whitespace, and a single line.

## Run

```sh
node main.ts
```
